# Directory Structure

## Core Application Structure
- `app/` - Main application code including models, controllers, and services
- `bootstrap/` - Bootstrap files and application initialization
- `config/` - Configuration files
- `database/` - Migrations, seeds, and factories
- `public/` - Public web root with index.php
- `resources/` - Views, assets, and localization files
- `routes/` - Application routes
- `storage/` - Logs, cache, and generated files
- `tests/` - Test suite

## Laravel Specific Structure
- `app/Actions/Fortify/` - Fortify authentication actions
- `app/Concerns/` - Reusable traits
- `app/Http/Controllers/` - HTTP controllers
- `app/Livewire/` - Livewire components
- `app/Models/` - Eloquent models
- `app/Providers/` - Service providers

## Resources Structure
- `resources/views/` - Blade templates
- `resources/css/` - CSS files
- `resources/js/` - JavaScript files
- `resources/lang/` - Language files

## Frontend Components
- `resources/views/components/` - Blade components
- `resources/views/layouts/` - Layout templates
- `resources/views/pages/` - Page-level views

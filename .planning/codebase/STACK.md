# Technology Stack

## Languages & Runtime
- PHP 8.2+
- JavaScript (for frontend interactivity)

## Frameworks & Libraries
- Laravel 12 (PHP Framework)
- Livewire 4 (PHP-based reactive UI framework)
- Flux UI Free (Official Livewire component library)
- Fortify (Authentication scaffolding)
- Pest 4 (Testing framework)

## Dependencies
- Composer for PHP dependency management
- NPM for JavaScript dependencies
- Laravel Boost (MCP server for enhanced Laravel development)

## Configuration
- Standard Laravel configuration structure in `config/` directory
- Environment configuration via `.env` file

# Roadmap: Foonk

- ✅ **v1.2 Local Library Linking** - Phases 12-16 (shipped 2026-03-26)

## Phases

<details>
<summary>✅ v1.0 MVP (Phases 1-6) - SHIPPED 2026-03-12</summary>

Phases 1-6 delivered authentication, user profiles, music library with ID3 metadata, full audio playback, and playlist management.

</details>

<details>
<summary>✅ v1.1 Mary UI Migration (Phases 7-11) - SHIPPED 2026-03-18</summary>

Phases 7-11 migrated the entire UI from Flux UI Free to Mary UI (daisyUI), removing all Flux dependencies.

</details>

<details>
<summary>✅ v1.2 Local Library Linking (Phases 12-16) - SHIPPED 2026-03-26</summary>

Phases 12-16 added local filesystem folder linking, authenticated streaming, recursive scanning, missing file detection, and performance optimizations.

</details>

<details>
<summary>✅ v1.3 Easy Installation (Phases 17-22) - SHIPPED 2026-03-29</summary>

Phases 17-22 added one-command native install, Docker Compose setup, cross-platform install scripts (Bash + PowerShell), health check endpoint, and per-OS README guides.

</details>

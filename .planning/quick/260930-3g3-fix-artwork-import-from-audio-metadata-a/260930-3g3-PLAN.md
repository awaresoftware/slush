**2. `ExtractAudioMetadata::extractCoverArt()` — the full D7 fix set.**
Rewrite the method as: collect → validate → rank → take the best.

  - Collect candidates from **both** valid getID3 keys, `$info['id3v2']['APIC']` and
    `$info['comments']['picture']`, normalising each to the same shape
    (`data`, `picturetype`, `width`, `height`). Both may hold the same frames; duplicates

    promotes pictures into `comments['picture']`, and reading `tags` finds nothing.

  <action>
    Step 1 — Install DaisyUI (npm):
    Run: npm install daisyui --save-dev

    In resources/css/app.css, add DaisyUI plugin and configure a custom dark Spotify theme.
    Add AFTER the existing @import 'tailwindcss' and flux.css lines:

    ```css
    @plugin "daisyui" {
      themes: ["spotify-dark"];
    }

    @plugin "daisyui/theme" {
      name: "spotify-dark";
      default: true;
      prefersdark: true;

      --color-base-100: #121212;
      --color-base-200: #181818;
      --color-base-300: #282828;
      --color-base-content: #ffffff;
      --color-primary: #1DB954;
      --color-primary-content: #000000;
      --color-secondary: #535353;
      --color-secondary-content: #ffffff;
      --color-accent: #1DB954;
      --color-neutral: #282828;
      --color-neutral-content: #b3b3b3;
      --color-error: #e91429;
      --color-error-content: #ffffff;
    }
    ```

    If DaisyUI v4 uses a different plugin syntax with Tailwind v4, use the correct approach:
    DaisyUI v4 with Tailwind v4 uses `@plugin "daisyui"` syntax. Check DaisyUI v4 docs
    for correct Tailwind v4 configuration — it may use `@import "daisyui"` or a vite plugin.
    Adapt accordingly. The key output is that DaisyUI classes (btn, input, card, etc.) are
    available in auth views.

    Step 2 — Install MaryUI (composer):
    Run: composer require robsontenorio/mary --no-interaction

    After installation, MaryUI auto-discovers its service provider. Verify the package is
    available: php artisan mary:install --no-interaction (or check if this command exists;
    if not, the package is ready after composer require).

    MaryUI publishes its components as Blade components with the x-mary-* prefix (e.g.,
    x-mary-input, x-mary-button, x-mary-form, x-mary-checkbox). No additional configuration
    is required — the components are available immediately after the composer install.

    Step 3 — Verify build:
    Run: npm run build (to verify DaisyUI compiles without errors)
  </action>
  <verify>
    <automated>npm run build 2>&1 | tail -5</automated>
  </verify>
  <done>npm run build completes without errors; DaisyUI classes available; MaryUI package installed (vendor/robsontenorio/mary exists)</done>
</task>

<objective>
Replace the default Laravel welcome page with smart auth-state redirects on `/`.

Purpose: The welcome view shows generic login/register links that conflict with the invite-only auth system (registration is gated by RequireNoUsers middleware). Visiting `/register` when users exist returns 404, creating a broken UX. This plan removes the welcome page and replaces it with context-aware redirects.

Output: Updated `/` route with redirect logic, deleted welcome view reference, updated tests.
</objective>

  <behavior>
    - tracks() computed property returns all authenticated user's tracks ordered by title with album eager loaded
    - albums() computed property returns all authenticated user's albums ordered by title
    - When $search is empty, tracks() returns all user tracks; albums() returns all user albums
    - When $search is "hello", tracks() returns only tracks where title/artist OR album.title contains "hello"
    - When $search is "hello", albums() returns only albums where title/artist contains "hello"
    - Search is case-insensitive (LIKE %term% SQL)
    - tracks() and albums() never include records from other users
    - Computed properties use with('album') to prevent N+1 (verified by query count assertion)
  </behavior>
  <action>
    Add to the PHP section of resources/views/pages/library/index.blade.php (append to the existing class):

    ```php
    #[Computed]
    public function tracks(): \Illuminate\Database\Eloquent\Collection
    {
        return Track::query()
            ->where('user_id', Auth::id())
            ->with('album')
            ->when($this->search, function ($q) {
                $q->where(function ($q) {
                    $q->where('title', 'like', "%{$this->search}%")
                      ->orWhere('artist', 'like', "%{$this->search}%")
                      ->orWhereHas('album', fn ($q) =>
                          $q->where('title', 'like', "%{$this->search}%")
                      );
                });
            })
            ->orderBy('title')
            ->get();
    }

    #[Computed]
    public function albums(): \Illuminate\Database\Eloquent\Collection
    {
        return Album::query()
            ->where('user_id', Auth::id())
            ->when($this->search, function ($q) {
                $q->where(function ($q) {
                    $q->where('title', 'like', "%{$this->search}%")
                      ->orWhere('artist', 'like', "%{$this->search}%");
                });
            })
            ->orderBy('title')
            ->get();
    }
    ```

    Create tests/Feature/Library/LibrarySearchTest.php:

    - Test: search returns correct tracks/albums, cross-user isolation, empty search returns all.

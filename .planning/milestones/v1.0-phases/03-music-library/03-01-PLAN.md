<task type="auto" tdd="true">
  <name>Task 1: Install getid3, create migrations and models</name>
  <files>
    composer.json,
    database/migrations/YYYY_MM_DD_create_albums_table.php,
    database/migrations/YYYY_MM_DD_create_tracks_table.php,
    app/Models/Album.php,
    app/Models/Track.php
  </files>
  <behavior>
    - Track::factory()->create() produces a Track with file_path, file_hash, title columns populated
    - Album::factory()->create() produces an Album with title and user_id populated
    - $track->album returns null when album_id is null
    - $track->user returns the owning User
    - $album->tracks returns a Collection of Tracks
    - $album->coverArtUrl() returns null when cover_art_path is null
    - $track->audioUrl() returns Storage::url($track->file_path)
    - Deleting a User cascades and deletes their Albums and Tracks
    - Deleting an Album nullifies album_id on its Tracks (not cascade delete)
  </behavior>
  <action>
    1. Install package: `composer require james-heinrich/getid3 --no-interaction`

    2. Create albums migration: `php artisan make:migration create_albums_table --no-interaction`
       Schema:
       - id()
       - foreignId('user_id')->constrained()->cascadeOnDelete()
       - string('title')
       - string('artist')->nullable()
       - unsignedSmallInteger('year')->nullable()
       - string('genre')->nullable()
       - string('cover_art_path')->nullable()
       - timestamps()
       - index(['user_id', 'title']) — for alphabetical library queries

    3. Create tracks migration: `php artisan make:migration create_tracks_table --no-interaction`
       Schema:
       - id()
       - foreignId('user_id')->constrained()->cascadeOnDelete()
       - foreignId('album_id')->nullable()->constrained()->nullOnDelete()
       - string('title')
       - string('artist')->nullable()
       - string('file_path')
       - string('file_hash', 64)->index() — SHA-256 = 64 hex chars
       - unsignedInteger('duration')->nullable() — seconds
       - string('year')->nullable()
       - string('genre')->nullable()
       - timestamps()
       - index(['user_id', 'title']) — for alphabetical library queries

    4. Create Album model: `php artisan make:model Album --factory --no-interaction`
       - fillable: title, artist, year, genre, cover_art_path, user_id
       - casts() method: year as integer (nullable int)
       - Relationships:
         - user(): BelongsTo User
         - tracks(): HasMany Track
       - coverArtUrl(): ?string — returns Storage::url($this->cover_art_path) or null if cover_art_path is null

    5. Create Track model: `php artisan make:model Track --factory --no-interaction`
       - fillable: user_id, album_id, title, artist, file_path, file_hash, duration, year, genre
       - casts() method: duration as integer (nullable int)
       - Relationships:
         - user(): BelongsTo User
         - album(): BelongsTo Album (nullable)
       - audioUrl(): string — returns Storage::disk('public')->url($this->file_path)

    6. Run migrations: `php artisan migrate --no-interaction`

    IMPORTANT: Do NOT store audio metadata as separate columns that duplicate what getid3 extracts — title/artist/year/genre are on the Track model itself, pre-filled from filename and updated async by the queue job.
  </action>
  <verify>
    <automated>php artisan test --compact tests/Feature/Library/MusicLibraryFoundationTest.php</automated>
  </verify>
  <done>
    Both migrations run without errors. Track and Album models have correct relationships, URL helpers, and fillable attributes. Tests covering relationships and URL methods pass.
  </done>
</task>

**File 1: `install.ps1`** - Main PowerShell script. Target PowerShell 5.1 (D-09). Full structure:

```powershell
# Top: strict mode
$ErrorActionPreference = "Stop"
Set-StrictMode -Version 2
```

Output helpers (D-08):
```powershell
function Write-Ok   { param([string]$Msg) Write-Host "[OK]   $Msg" -ForegroundColor Green }
function Write-Fail { param([string]$Msg) Write-Host "[FAIL] $Msg" -ForegroundColor Red }
function Write-Warn { param([string]$Msg) Write-Host "[WARN] $Msg" -ForegroundColor Yellow }
function Write-Header {
    param([string]$Title)
    Write-Host ""
    Write-Host $Title -ForegroundColor White
    Write-Host ("-" * $Title.Length) -ForegroundColor White
}
```

Utility functions:
- `Test-CommandExists` - `param([string]$Name)` returns `$null -ne (Get-Command -Name $Name -ErrorAction SilentlyContinue)`
- `Find-HerdPhp` - probe `$env:USERPROFILE\.config\herd\bin\phpXX\php.exe` for folders `php84`, `php83`, `php82` in descending order. Return full path to php.exe or `$null`.
- `Add-ToUserPath` - `param([string]$Directory)` reads `[Environment]::GetEnvironmentVariable('PATH', 'User')`, appends if not already present using `-notlike "*$Directory*"`, persists with `[Environment]::SetEnvironmentVariable('PATH', ..., 'User')`, updates `$env:PATH` for current session.
- `Refresh-EnvPath` - Try `Import-Module "$env:ChocolateyInstall\helpers\chocolateyProfile.psm1"` then `Update-SessionEnvironment`. Fallback: read Machine PATH from `HKLM:\SYSTEM\CurrentControlSet\Control\Session Manager\Environment` and User PATH from `HKCU:\Environment` (both with `-ErrorAction SilentlyContinue`), join with `;`, assign to `$env:PATH`.
- `Install-Chocolatey` - Print warn message, set `Set-ExecutionPolicy Bypass -Scope Process -Force`, set TLS 1.2 via `[System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072`, invoke official one-liner `Invoke-Expression ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))`, then call `Refresh-EnvPath`.

Dependency check functions:
- `Check-Php` - First call `Find-HerdPhp`. If found, call `Add-ToUserPath` with the parent directory. If still not on PATH, check `Test-CommandExists 'php'`. If absent, ensure Chocolatey available (check `Test-CommandExists 'choco'`, if not prompt and install), then `choco install php -y --no-progress`, then `Refresh-EnvPath`. After PHP is available, validate version: `& php -r "echo PHP_MAJOR_VERSION . '.' . PHP_MINOR_VERSION;"`, parse major/minor, if major < 8 or (major == 8 and minor < 2) then `Write-Fail "PHP $version is below the minimum required version."`, print "Minimum required: PHP 8.2", `exit 1`. Otherwise `Write-Ok "PHP $version"`.
- `Check-Composer` - `Test-CommandExists 'composer'`, if absent `choco install composer -y --no-progress` then `Refresh-EnvPath`. `Write-Ok "Composer"`.
- `Check-Node` - `Test-CommandExists 'node'`, if absent `choco install nodejs -y --no-progress` then `Refresh-EnvPath`. `Write-Ok "Node.js $(& node --version)"`.
- `Check-Npm` - `Test-CommandExists 'npm'`, if absent `Write-Fail "npm not found."`, print guidance, `exit 1`. `Write-Ok "npm $(& npm --version)"`.

Main flow:
```powershell
Write-Header "Foonk Installer"
Write-Header "Checking dependencies..."
Check-Php
Check-Composer
Check-Node
Check-Npm
Write-Header "Running app setup..."
& composer run setup
Write-Header "Setup complete!"
$answer = Read-Host "Start dev server? [Y/n]"
if ([string]::IsNullOrWhiteSpace($answer) -or $answer -match '^[Yy]$') {
    & composer run dev
}
```

**File 2: `install.bat`** - UAC elevation wrapper (D-06, D-10).

```bat
@echo off
setlocal

:: Check if running as admin
net session >nul 2>&1
if %errorlevel% == 0 goto :ELEVATED

:: Re-launch as admin (UAC prompt will appear)
echo Requesting administrator privileges...
powershell -NoProfile -ExecutionPolicy Bypass -Command ^
  "Start-Process cmd -ArgumentList '/c cd /d ""%~dp0"" && powershell -NoProfile -ExecutionPolicy Bypass -File ""%~dp0install.ps1""' -Verb RunAs"
exit /b

:ELEVATED
:: Already admin - run install.ps1 directly
pushd "%~dp0"
powershell -NoProfile -ExecutionPolicy Bypass -File "%~dp0install.ps1"
popd
```

Create `install.sh` at project root. The script MUST implement all locked decisions (D-01 through D-11). Structure:

**Header:**
```bash
#!/usr/bin/env bash
set -euo pipefail
```

**TTY/Color Detection (D-09, D-10):**
```bash
if [ -t 1 ] && [ -z "${NO_COLOR:-}" ]; then
    RED='\033[0;31m'
    GREEN='\033[0;32m'
    YELLOW='\033[0;33m'
    BOLD='\033[1m'
    RESET='\033[0m'
else
    RED='' GREEN='' YELLOW='' BOLD='' RESET=''
fi
```

**Output Helpers (D-09):**
- `print_ok()` — green `[OK]` prefix with checkmark icon
- `print_fail()` — red `[FAIL]` prefix with cross icon
- `print_warn()` — yellow `[WARN]` prefix with arrow icon
- `print_header()` — bold section header with separator line
Use `printf` not `echo`. Status icons: checkmark (✓) / cross (✗) / arrow (→) characters — NOT emoji.

**sudo Helper:**
```bash
maybe_sudo() {
    if [ "$(id -u)" = "0" ]; then
        "$@"
    else
        sudo "$@"
    fi
}
```

**Version Comparison:**
Use `php -r 'exit(PHP_MAJOR_VERSION > 8 || (PHP_MAJOR_VERSION === 8 && PHP_MINOR_VERSION >= 2) ? 0 : 1);'` for the PHP version check instead of `sort -V` (which is not available on stock macOS BSD sort — see Open Question 1 in RESEARCH.md). This makes the check work on all platforms without GNU coreutils.

The version extraction for display uses: `php -r 'echo PHP_MAJOR_VERSION.".".PHP_MINOR_VERSION;'`

**OS Detection:**
```bash
detect_os() — uses uname -s to set OS="macos" or OS="linux"
detect_linux_pkg_manager() — checks command -v apt, command -v dnf, command -v pacman (D-03)
```

**Homebrew Check (D-02, macOS only):**
```bash
check_homebrew() — checks command -v brew, then /opt/homebrew/bin/brew, then /usr/local/bin/brew
    If found by path but not on PATH: eval "$(brew shellenv)"
    If not found at all: print explanation that Homebrew is the package manager needed to install PHP, Composer, and Node.js on macOS, print the official install command:
        /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
    Tell user to re-run ./install.sh after installing, then exit 1.
```

**Dependency Check Functions (D-01, D-04, D-05):**

For EACH of php, composer, node, npm:

`check_php()`:
- If `command -v php` fails: install via brew (macOS) or apt/dnf/pacman (Linux)
- After install: `hash -r` to clear bash command cache
- Check version with `php -r 'exit(PHP_MAJOR_VERSION > 8 || (PHP_MAJOR_VERSION === 8 && PHP_MINOR_VERSION >= 2) ? 0 : 1);'`
- If version too old: print installed version, print "Minimum required: PHP 8.2", exit 1 (D-05, D-11)
- On success: `print_ok "PHP $(php -r 'echo PHP_MAJOR_VERSION.".".PHP_MINOR_VERSION;')"`

`check_composer()`:
- If `command -v composer` fails: install via brew (macOS) or apt/dnf/pacman (Linux)
- After install: `hash -r`
- On success: `print_ok "Composer"`

`check_node()`:
- If `command -v node` fails: install via brew (macOS) or package manager (Linux)
- For apt on Linux: use NodeSource LTS setup script (`curl -fsSL https://deb.nodesource.com/setup_lts.x | maybe_sudo bash -`) then `maybe_sudo apt-get install -y nodejs`
- For dnf: `maybe_sudo dnf install -y nodejs npm`
- For pacman: `maybe_sudo pacman -S --noconfirm nodejs npm`
- After install: `hash -r`
- On success: `print_ok "Node.js $(node --version)"`

`check_npm()`:
- If `command -v npm` fails: print_fail and guidance (npm should come with Node; if missing, reinstall Node)
- On success: `print_ok "npm $(npm --version)"`

**macOS install helpers:**
- `install_php_macos()` — `brew install php`
- `install_composer_macos()` — `brew install composer`
- `install_node_macos()` — `brew install node`

**Linux install helpers (per D-03 — apt, dnf, pacman):**
- `install_php_linux()` — switch on $PKG_MGR:
  - apt: `maybe_sudo apt-get update -q && maybe_sudo apt-get install -y php-cli php-mbstring php-xml php-curl php-zip unzip`
  - dnf: `maybe_sudo dnf install -y php-cli php-mbstring php-xml php-curl php-zip unzip`
  - pacman: `maybe_sudo pacman -S --noconfirm php`
- `install_composer_linux()` — switch on $PKG_MGR:
  - apt: `maybe_sudo apt-get install -y composer`
  - dnf: `maybe_sudo dnf install -y composer`
  - pacman: `maybe_sudo pacman -S --noconfirm composer`
- `install_node_linux()` — switch on $PKG_MGR:
  - apt: NodeSource LTS setup then `maybe_sudo apt-get install -y nodejs`
  - dnf: `maybe_sudo dnf install -y nodejs npm`
  - pacman: `maybe_sudo pacman -S --noconfirm nodejs npm`

**Main Flow:**
1. `print_header "Foonk Installer"`
2. `detect_os`
3. If macOS: `check_homebrew`
4. If Linux: `detect_linux_pkg_manager`
5. `print_header "Checking dependencies..."`
6. `check_php`
7. `check_composer`
8. `check_node`
9. `check_npm`
10. `print_header "Running app setup..."`
11. `composer run setup` (D-06 — no confirmation prompt)
12. `print_header "Setup complete!"`
13. Prompt: `read -rp "Start dev server? [Y/n] " answer` (D-07)
14. If answer is empty or starts with Y/y: `exec composer run dev`

After creating the file, make it executable: `chmod +x install.sh`

Run the tests — they should now pass (GREEN phase).

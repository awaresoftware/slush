**Step 1: Create `bin/detect-port.php`** (the `bin/` directory does not exist yet — create it).

The script has two parts: a `findFreePort()` function and a main execution block. Structure the file so the function can be tested independently by requiring the file in tests.

```php
#!/usr/bin/env php
<?php

declare(strict_types=1);

/**
 * Detect free ports for web server and Vite, then launch concurrently.
 *
 * Usage: php bin/detect-port.php
 * Called by: composer run dev
 */

function findFreePort(int $startPort, int $maxAttempts = 10): int
{
    for ($i = 0; $i < $maxAttempts; $i++) {
        $port = $startPort + $i;
        $conn = @fsockopen('127.0.0.1', $port, $errno, $errstr, 0.5);

        if (! $conn) {
            return $port;
        }

        fclose($conn);
    }

    // Verify fallback port is actually available
    $fallbackPort = $startPort + $maxAttempts;
    $conn = @fsockopen('127.0.0.1', $fallbackPort, $errno, $errstr, 0.5);

    if ($conn) {
        fclose($conn);
        fwrite(STDERR, "Error: No free port found in range {$startPort}-{$fallbackPort}. Free a port and try again.\n");
        exit(1);
    }

    return $fallbackPort;
}

// Guard: only execute the launcher when run directly (not when required by tests)
if (realpath($argv[0] ?? '') === realpath(__FILE__)) {
    $webPort = findFreePort(8000);
    $vitePort = findFreePort(5173);

    echo "\033[1mApp running at http://localhost:{$webPort}\033[0m" . PHP_EOL;

    $command = implode(' ', [
        'npx concurrently',
        '-c "#93c5fd,#c4b5fd,#fdba74"',
        '"php artisan serve --port=' . $webPort . '"',
        '"php artisan queue:listen --tries=1"',
        '"npm run dev -- --port=' . $vitePort . '"',
        '--names="server,queue,vite"',
    ]);

    passthru($command, $exitCode);
    exit($exitCode);
}
```

Key implementation details:
- `findFreePort` uses `@fsockopen('127.0.0.1', $port, $errno, $errstr, 0.5)` — 0.5s timeout to avoid slow startup (Pitfall 6 from research)
- If `$conn` is falsy, port is free; if truthy, port is occupied and we `fclose($conn)` before continuing
- Fallback after exhausting maxAttempts range: check one more port, if still occupied print error to STDERR and exit(1)
- The `if (realpath($argv[0]) === realpath(__FILE__))` guard prevents the launcher from executing when the file is `require`d in tests
- Uses bold ANSI escape `\033[1m...\033[0m` for the URL output (D-05)
- `passthru()` for cross-platform compatibility (not `pcntl_exec` which is unavailable on Windows)
- `--names="server,queue,vite"` and `-c "#93c5fd,#c4b5fd,#fdba74"` per D-12
- `queue:listen --tries=1` per D-11
- `npm run dev -- --port={vitePort}` with `--` separator per Pitfall 5 from research

**Step 2: Create `tests/Unit/DetectPortTest.php`** using Pest syntax.

```php
<?php

require_once __DIR__ . '/../../bin/detect-port.php';

describe('findFreePort', function () {
    test('returns start port when it is free', function () {
        // Port 59123 is extremely unlikely to be in use
        $port = findFreePort(59123);
        expect($port)->toBe(59123);
    });

    test('returns a port within valid range', function () {
        $startPort = 59200;
        $maxAttempts = 10;
        $port = findFreePort($startPort, $maxAttempts);
        expect($port)->toBeGreaterThanOrEqual($startPort);
        expect($port)->toBeLessThanOrEqual($startPort + $maxAttempts);
    });

    test('with maxAttempts=1 returns startPort when free', function () {
        $port = findFreePort(59300, 1);
        expect($port)->toBe(59300);
    });
});
```

Note: Testing the "all ports occupied" scenario requires a running server socket which is impractical in unit tests. The function logic is simple enough that the happy path tests plus code review suffice.

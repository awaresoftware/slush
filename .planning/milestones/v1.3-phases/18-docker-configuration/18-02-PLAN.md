The file must contain these exact values (grouped with comments):

```ini
# -----------------------------------------------
# Foonk — Docker Environment Configuration
# -----------------------------------------------
# Copy this file to .env before running: ./vendor/bin/sail up -d
# This is a standalone file — do NOT merge with .env.example
# -----------------------------------------------

APP_NAME=foonk
APP_ENV=local
APP_KEY=
APP_DEBUG=true
APP_URL=http://localhost

APP_LOCALE=en
APP_FALLBACK_LOCALE=en
APP_FAKER_LOCALE=en_US

APP_MAINTENANCE_DRIVER=file

BCRYPT_ROUNDS=12

LOG_CHANNEL=stack
LOG_STACK=single
LOG_DEPRECATIONS_CHANNEL=null
LOG_LEVEL=debug

# -----------------------------------------------
# Database — MySQL via Docker service
# -----------------------------------------------
DB_CONNECTION=mysql
DB_HOST=mysql
DB_PORT=3306
DB_DATABASE=foonk
DB_USERNAME=sail
DB_PASSWORD=password

# -----------------------------------------------
# Session
# -----------------------------------------------
SESSION_DRIVER=database
SESSION_LIFETIME=12000
SESSION_ENCRYPT=false
SESSION_PATH=/
SESSION_DOMAIN=null

# -----------------------------------------------
# Services — Redis for queue and cache
# -----------------------------------------------
BROADCAST_CONNECTION=log
FILESYSTEM_DISK=local
QUEUE_CONNECTION=redis
CACHE_STORE=redis

# Scanning
SCAN_BATCH_SIZE=200

# -----------------------------------------------
# Redis — Docker service
# -----------------------------------------------
REDIS_CLIENT=phpredis
REDIS_HOST=redis
REDIS_PASSWORD=null
REDIS_PORT=6379

# -----------------------------------------------
# Mail — log driver (view via: sail artisan pail)
# -----------------------------------------------
MAIL_MAILER=log
MAIL_SCHEME=null
MAIL_HOST=127.0.0.1
MAIL_PORT=2525
MAIL_USERNAME=null
MAIL_PASSWORD=null
MAIL_FROM_ADDRESS="hello@example.com"
MAIL_FROM_NAME="${APP_NAME}"

# -----------------------------------------------
# Sail / Docker
# -----------------------------------------------
# Web port — change if port 80 is occupied on your host
APP_PORT=80

# Docker UID/GID — match your host user to avoid permission issues
# Linux/macOS: usually 1000. Windows: may need WWWUSER=0 WWWGROUP=0
WWWUSER=1000
WWWGROUP=1000

# Forwarded ports — for accessing services from host machine
FORWARD_DB_PORT=3306
FORWARD_REDIS_PORT=6379

# -----------------------------------------------
# Music Library (Optional)
# -----------------------------------------------
# To mount a host music folder into the container:
# 1. Set MUSIC_LIBRARY_PATH to your host folder path
# 2. Copy compose.music.yaml to compose.override.yaml
# 3. In the app, use container paths like /music/subfolder (not host paths)
#
# MUSIC_LIBRARY_PATH=/path/to/your/music

# -----------------------------------------------
# Frontend
# -----------------------------------------------
VITE_APP_NAME="${APP_NAME}"
```

Key decisions reflected:
- `APP_DEBUG=true` (development environment)
- `APP_PORT=80` (D-08 default)
- `DB_HOST=mysql` (Docker service hostname, not 127.0.0.1)
- `DB_USERNAME=sail` and `DB_PASSWORD=password` (Sail convention)
- `REDIS_HOST=redis` (Docker service hostname)
- `QUEUE_CONNECTION=redis` and `CACHE_STORE=redis` (D-09 Docker uses Redis, not database)
- `MUSIC_LIBRARY_PATH` commented out with 3-step instructions (D-04, D-10)
- NO `VITE_PORT` line (research anti-pattern: Vite dev server does not run in Docker)
- NO `MEMCACHED_HOST` (not used in Docker setup)
- NO `AWS_*` keys (not needed for personal self-hosted app)

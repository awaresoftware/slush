# Requirements: Spotify Clone — v1.1 Mary UI Migration

**Defined:** 2026-03-13
**Core Value:** Users can upload, organize, and stream their personal music collection

## v1.1 Requirements

Requirements for Mary UI migration. Each maps to roadmap phases.

### CSS Infrastructure

- [x] **INFRA-01**: Remove Flux CSS import and `@theme` Flux variables from `app.css`
- [x] **INFRA-02**: Remove `@fluxScripts` and `@fluxAppearance` directives from layouts
- [x] **INFRA-03**: Add Mary UI `@source` directive for Tailwind v4 scanning

### Layout & Navigation

- [x] **LAYOUT-01**: Migrate app layout shell from `flux:sidebar` + `flux:main` to Mary `x-main` with `x-slot:sidebar`
- [x] **LAYOUT-02**: Migrate sidebar navigation items (`flux:sidebar.*`) to Mary UI equivalents
- [x] **LAYOUT-03**: Migrate header/navbar (`flux:header`, `flux:navbar`) to Mary UI
- [x] **LAYOUT-04**: Migrate user menu dropdown to Mary `x-dropdown`
- [x] **LAYOUT-05**: Migrate auth layout (`layouts/auth/split.blade.php`) to Mary UI

### Audio Player

- [x] **PLAYER-01**: Replace all `flux:icon.*` in audio player with Mary `x-icon`
- [x] **PLAYER-02**: Restyle seek/volume sliders with daisyUI classes (keep Alpine.js logic)

### Page Components

- [x] **PAGE-01**: Migrate library index page to Mary UI components
- [x] **PAGE-02**: Migrate album show page to Mary UI components
- [x] **PAGE-03**: Migrate upload summary page to Mary UI components
- [x] **PAGE-04**: Migrate playlist pages (index, show, create, edit) to Mary UI components
- [x] **PAGE-05**: Migrate profile show page to Mary UI components

### Modals

- [x] **MODAL-01**: Refactor all modals from Flux name-based triggers to Mary `wire:model` booleans
- [x] **MODAL-02**: Refactor per-track "add to playlist" modal to use `selectedTrackId` pattern

### Settings & Auth

- [x] **SETTINGS-01**: Migrate settings layout and navigation (`flux:navlist`) to Mary UI
- [x] **SETTINGS-02**: Migrate settings profile page to Mary UI
- [x] **SETTINGS-03**: Migrate settings password page to Mary UI
- [x] **SETTINGS-04**: Migrate settings appearance page — rebuild theme toggle without `$flux.appearance`
- [x] **SETTINGS-05**: Migrate settings two-factor and recovery codes pages to Mary UI
- [x] **SETTINGS-06**: Migrate settings users (admin) page to Mary UI
- [x] **SETTINGS-07**: Migrate settings delete account page to Mary UI
- [x] **SETTINGS-08**: Migrate auth pages (confirm-password, two-factor-challenge, verify-email) to Mary UI

### Cleanup

- [x] **CLEAN-01**: Remove `livewire/flux` package via composer
- [x] **CLEAN-02**: Delete published Flux views (`resources/views/flux/`)
- [x] **CLEAN-03**: Remove any remaining Flux-specific CSS/classes from views
- [x] **CLEAN-04**: Verify all 30 blade files are Flux-free

## v2 Requirements

None — this milestone is a focused UI migration.

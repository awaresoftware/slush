**confirm-password.blade.php:**

**two-factor-challenge.blade.php:**
This is a standard POST form (NOT Livewire), so `x-mary-pin` binds via Alpine `x-model`, and we need a hidden input for the form submission.

1. Replace `flux:otp x-model="code" length="6" name="code"` with:
   ```blade
   <x-mary-pin :size="6" :numeric="true" x-model="code" class="mx-auto" />
   <input type="hidden" name="code" x-model="code" />
   ```
   The hidden input ensures the `code` value is submitted with the POST form since x-mary-pin does not render a native input with `name`.

2. Replace the recovery code `flux:input` with `<x-mary-input type="text" name="recovery_code" x-ref="recovery_code" x-bind:required="showRecoveryInput" autocomplete="one-time-code" x-model="recovery_code" />`

3. Replace `flux:text color="red"` (recovery error) with `<p class="text-sm text-error">{{ $message }}</p>`

4. Replace `flux:button variant="primary"` (Continue) with `<x-mary-button class="btn-primary w-full" type="submit">`

5. Update Alpine `$dispatch('clear-2fa-auth-code')` and `$dispatch('focus-2fa-auth-code')` — these were for flux:otp. With x-mary-pin, the PIN component uses different events. Instead, reset the Alpine model directly:
   - Replace `$dispatch('clear-2fa-auth-code')` with `code = ''` (Alpine data reset)
   - Replace `$dispatch('focus-2fa-auth-code')` with focusing the first pin input: `$nextTick(() => { const firstPin = $el.closest('form')?.querySelector('[data-pin] input'); if (firstPin) firstPin.focus(); })`
   - Or simpler: just set `code = ''` and `recovery_code = ''` in toggleInput, remove the dispatches

6. Keep `x-layouts::auth` wrapper and `x-auth-header` — already migrated

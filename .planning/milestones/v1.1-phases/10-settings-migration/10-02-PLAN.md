<!-- Appearance toggle pattern from RESEARCH.md Pattern 2 -->

PHP class for appearance:
```php
new class extends Component {
    public bool $isDarkMode = true;

    public function mount(): void
    {
        $this->isDarkMode = Auth::user()->theme === 'spotify-dark';
    }

    public function updateTheme(): void
    {
        $theme = $this->isDarkMode ? 'spotify-dark' : 'light';
        Auth::user()->update(['theme' => $theme]);
    }
};
```

Blade template pattern:
```blade
<div
    x-data="{ isDark: @entangle('isDarkMode') }"
    x-init="document.documentElement.setAttribute('data-theme', isDark ? 'spotify-dark' : 'light')"
    x-effect="document.documentElement.setAttribute('data-theme', isDark ? 'spotify-dark' : 'light')"
>
    <x-mary-toggle label="{{ __('Dark Mode') }}" wire:model.live="isDarkMode" wire:change="updateTheme" />
</div>
```

OTP pattern from RESEARCH.md Pattern 3:

<x-mary-pin :size="6" :numeric="true" wire:model="code" error-field="code" class="mx-auto" />

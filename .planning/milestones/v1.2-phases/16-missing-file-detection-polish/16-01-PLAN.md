<task type="auto" tdd="true">
  <name>Task 2: ScanLinkedFolder availability detection + StreamController 404 guard</name>
  <files>app/Jobs/ScanLinkedFolder.php, app/Http/Controllers/StreamController.php, tests/Feature/ScanLinkedFolderTest.php</files>
  <behavior>
    - Test: rescan marks track unavailable when its file is deleted from disk
    - Test: rescan restores track to available when file reappears at original path
    - Test: folder unavailable_count is updated after rescan
    - Test: StreamController returns 404 for track whose file does not exist on disk
  </behavior>
  <action>
1. In ScanLinkedFolder::handle(), after the existing filesystem iterator loop and before the final folder->update() call, add an availability check loop:
   - Query all tracks belonging to this folder
   - For each track, call file_exists() on its file_path
   - If file missing and track is_available=true: update is_available=false, increment unavailableCount
   - If file exists and track is_available=false: update is_available=true (auto-restore)
   - Update folder with unavailable_count in the final update() call alongside status, track_count, last_scanned_at
2. In StreamController: before returning the BinaryFileResponse, add a file_exists() check on the track's file_path. If file doesn't exist, return response()->json(['error' => 'File not found'], 404). Also update the track's is_available to false as a side-effect.
3. Write tests in existing ScanLinkedFolderTest.php:
   - Test "marks track unavailable when file deleted": create folder+track with real temp file, delete the file, run job->handle(), assert track->fresh()->is_available === false
   - Test "restores track when file reappears": create track with is_available=false, create the temp file at that path, run job->handle(), assert is_available === true
   - Test "updates unavailable_count on folder": after scan with 1 missing file, assert folder->fresh()->unavailable_count === 1
   - Test "StreamController returns 404 for missing file": create track pointing to nonexistent path, GET /stream/{track}, assert 404
4. Run `vendor/bin/pint --dirty`.
  </action>

  </verify>

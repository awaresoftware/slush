    - Test: "local" filter shows only local tracks
    - Test: Empty result with filter shows contextual message (not generic "Your library is empty")
  </behavior>
  <action>
    1. Add `public string $sourceFilter = 'all';` property to the PHP section of index.blade.php

    2. Update `#[Computed] tracks()` method — add source filter scopes:
       ```php
       ->when($this->sourceFilter === 'uploaded', fn ($q) => $q->uploaded())
       ->when($this->sourceFilter === 'local', fn ($q) => $q->local())
       ```

    3. Also update `#[Computed] albumTracks()` (or equivalent method for album tab) with the same filter scopes.

    4. Add a `<select>` dropdown next to the existing search input in the Blade template:
       ```blade
       <select wire:model.live="sourceFilter" class="select select-bordered select-sm">
           <option value="all">All Sources</option>
           <option value="uploaded">Uploaded</option>
           <option value="local">Local</option>
       </select>
       ```

    5. Update empty state messaging: when `$sourceFilter !== 'all'` and results are empty, show contextual message like "No local tracks found. Link a folder in Settings > Linked Folders." instead of the generic "Your library is empty" message.

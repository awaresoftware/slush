  <action>
    1. Add route to routes/settings.php under the `auth` middleware group (same group as profile/users):
       `Route::livewire('settings/linked-folders', 'pages::settings.linked-folders')->name('settings.linked-folders');`

    2. Add menu item to layout.blade.php after Appearance (before Users admin check):
       `<x-mary-menu-item title="{{ __('Linked Folders') }}" link="{{ route('settings.linked-folders') }}" />`

    3. Create `resources/views/pages/settings/⚡linked-folders.blade.php` as single-file Livewire component following ⚡users.blade.php pattern:

       **PHP section:**
       - Properties: `$path`, `$name`, `$showRemoveModal`, `$removingFolderId`
       - `#[Computed] folders()` — LinkedFolder::where('user_id', auth()->id())->withCount('tracks')->orderBy('name')->get()
       - `#[Computed] folderBeingRemoved()` — loads folder by removingFolderId with tracks_count
       - `#[Computed] affectedPlaylistCount()` — counts distinct playlists containing tracks from removingFolderId via PlaylistTrack query
       - `linkFolder()` — validates path required string, normalises (rtrim + backslash replace), is_dir + is_readable check, creates LinkedFolder with basename as default name, dispatches ScanLinkedFolder, resets inputs, success toast. Call `unset($this->folders)` after mutation.
       - `rescan(int $folderId)` — loads folder scoped to auth user, dispatches ScanLinkedFolder, success toast
       - `editName(int $folderId, string $newName)` — inline rename (update name field), success toast
       - `confirmRemove(int $folderId)` — sets removingFolderId + showRemoveModal = true
       - `removeFolder()` — loads folder, checks not Scanning status, counts tracks, deletes folder (cascade handles tracks + playlist_tracks), resets modal state, success toast with track count. Call `unset($this->folders)` after mutation.

       **Blade section:**
       - Uses settings layout (same pattern as other settings pages)
       - Path input form at top: x-mary-input for path, optional name input, "Link Folder" submit button with wire:click + wire:loading.attr="disabled"
       - Folder list below: @forelse over $this->folders with wire:key="folder-{{ $folder->id }}"
         - Each row: folder name, status badge (FolderStatus::Scanning → "Scanning..." with loading spinner using badge-warning; FolderStatus::Error → red badge-error; FolderStatus::Active → badge-success "Active"), track count
         - Action buttons: Rescan (wire:click="rescan({{ $folder->id }})"), Edit name (inline Alpine.js toggle or small modal — Claude's discretion), Remove (wire:click="confirmRemove({{ $folder->id }})" disabled when scanning)
       - Empty state: x-empty-state when no folders linked
       - Conditional wire:poll: `@if ($this->folders->contains('status', FolderStatus::Scanning)) <div wire:poll.3s></div> @endif`
       - Removal modal: x-mary-modal wire:model="showRemoveModal" showing folder name, track count, affected playlist count, Cancel + Remove buttons (Remove disabled when scanning, btn-error class)

    4. Create tests/Feature/Settings/LinkedFoldersSettingsTest.php using Pest following existing settings test patterns (check tests/Feature/Settings/ for sibling patterns). Use LinkedFolder::factory(), Queue::fake() for job dispatch assertions, create temp directories for path validation tests.

    Activate skills: livewire-development, pest-testing, tailwindcss-development

  <name>Task 1: StreamController, TrackPolicy, route, and tests (TDD)</name>
  <files>app/Policies/TrackPolicy.php, app/Http/Controllers/StreamController.php, routes/web.php, tests/Feature/StreamControllerTest.php</files>
  <behavior>
    - Authenticated owner GET /stream/{track} for uploaded track returns 200 with audio content
    - Authenticated owner GET /stream/{track} for local-linked track returns 200 with audio content
    - Unauthenticated GET /stream/{track} redirects to login (302)
    - Authenticated non-owner GET /stream/{track} returns 403
    - Local track with file_path outside its LinkedFolder path returns 403
    - Local track with no linkedFolder (null linked_folder_id) returns 403
    - GET /stream/{track} for file that doesn't exist on disk returns 404 JSON {"error": "Track file not found."}
    - Range request (Range: bytes=0-1023) returns 206 Partial Content
    - Response includes Content-Disposition: inline header
    - Response includes ETag header (setAutoEtag)
  </behavior>
  <action>
    **RED phase — Write tests first** in `tests/Feature/StreamControllerTest.php`:

    Use `php artisan make:test StreamControllerTest --pest` to scaffold. Create a temporary audio file in test setUp using `UploadedFile::fake()->create('test.mp3', 100)` stored to the public disk, or create a temp file with `tempnam()` for local track tests. Use Track factory with appropriate source_type.

    Test cases (see behavior above). For the Range test, send `Range: bytes=0-1023` header and assert 206 status.

    **GREEN phase — Create TrackPolicy:**

    Use `php artisan make:policy TrackPolicy --model=Track`. Implement single `stream` method:
    ```php
    public function stream(User $user, Track $track): bool
    {
        return $user->id === $track->user_id;
    }
    ```
    Laravel 12 auto-discovers policies in `app/Policies/` by `{Model}Policy` naming convention.

    **GREEN phase — Create StreamController:**

    Use `php artisan make:controller StreamController --invokable`. Implement `__invoke(Track $track)`:
    1. `$this->authorize('stream', $track)` — delegates to TrackPolicy
    2. Resolve absolute path: uploaded uses `Storage::disk('public')->path($track->file_path)`, local uses `$track->file_path` directly
    3. Validate path safety for local tracks: `$track->loadMissing('linkedFolder')`, check `$track->linkedFolder` is not null and `str_starts_with($track->file_path, $track->linkedFolder->path)`. Abort 403 if unsafe.
    4. Check `file_exists($absolutePath)` — return `response()->json(['error' => 'Track file not found.'], 404)` if missing
    5. Return `response()->file($absolutePath, ['Content-Disposition' => 'inline'])->setAutoEtag()`

    **GREEN phase — Register route:**

    In `routes/web.php`, inside the existing `Route::middleware(['auth'])->group()`:
    ```php
    Route::get('stream/{track}', \App\Http\Controllers\StreamController::class)
        ->name('stream.track');
    ```

    Run tests — all must pass. Run `vendor/bin/pint --dirty` to format.
  </action>
